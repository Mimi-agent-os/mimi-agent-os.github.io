mimi-os

mimi-os is a personal agent runtime. The gateway daemon holds the models and the secure channel; agents built on the SDK connect to it, and the app pairs with it to talk to them and control them. The front page shows it at work.

Every part is its own repo under Mimi-agent-os. This wiki reads each one's README and docs from GitHub as you open them, so it shows what is on main right now.
