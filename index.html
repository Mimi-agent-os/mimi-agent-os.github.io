What is it?

Your own AI agents, on your own machines.

mimi-os runs your agents on a machine at home, around the clock, and puts all of them in one app on your desktop and your phone.

Get started Read the wiki GitHub

Why mimi-os?

Agents are code you own.

Each agent is a folder in your git repo: a persona in markdown, tools as plain TypeScript functions, and tests you run like any other code.

Easy to run. One command sets up each machine, and one link pairs the app.

A diagram: the app on your desktop or phone, the gateway on your machine at home with its models and agents, and Tailscale or your own network between them. The channel is end-to-end encrypted, with a Noise IK handshake, an ML-KEM-768 key exchange and the gateway’s key pinned at pairing. A message is plain text in the app and in the gateway, and ciphertext on the network in between.

Start in three steps.

  1. Set up the gatewayOne command on the machine that will run it.
  2. Pair the appBuild it for a Mac, a Windows PC or an Android phone, then open one link.
  3. Add an agentWrite your own in TypeScript, or bring one someone shared.
